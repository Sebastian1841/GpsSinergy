# Icon Components

Componentes de iconografia compartida.

## Archivos

- `SvgIcon.vue`: wrapper para renderizar iconos SVG centralizados. Incluye iconos operativos reutilizables como `mantenciones`, `ok`, `vencida`, `configuracion` y `llave`. Los iconos usados en KPI deben quedar opticamente centrados dentro de un `viewBox` 24x24 para que puedan reutilizarse dentro de botones, tarjetas y badges sin ajustes locales.

## Regla de mantenimiento

Agregar aqui solo piezas de iconografia reutilizables. Iconos especificos de una pantalla pueden vivir cerca de su componente.

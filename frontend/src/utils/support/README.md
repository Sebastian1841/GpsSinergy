# Support Utils

`supportRequestUtils.js` define tipos, estados, etiquetas, alcance de lectura/
gestion y validacion de adjuntos. Tipos: instalacion GPS, retiro/traslado,
falla tecnica y consulta. Estados: recibida, revision, esperando cliente,
agendada y resuelta. `supportRequestUtils.test.js` cubre etiquetas y limites.

El soporte es una pagina independiente, no una nueva opcion de la sidebar.
